# GameStage1

A MonoGame C# project for game development.

## Prerequisites

- .NET 9.0 SDK or later
- MonoGame Content Builder

## Building

```bash
dotnet build
```

## Running

```bash
dotnet run
```

## Project Structure

- `Game1.cs` - Main game logic
- `Program.cs` - Entry point
- `Content/` - Game assets (images, sprites, etc.)
- `Content/Content.mgcb` - MonoGame content configuration

## Content

This project includes the following game assets:
- body.png
- cobblestone.png
- image.png
- log.png
- plank.png
- square.png
